# Generating Video Content with AI

This document explains how to use an AI assistant (like GPT-4, Claude, or Gemini) to generate the `content.json` file for creating new educational videos with this Remotion project.

## The `content.json` Schema

The `content.json` file is the heart of the video. It defines the text and data that will be displayed in each scene. The file must follow a specific structure (a JSON schema) to be valid.

Here is the schema with an explanation of each field:

```json
{
  "title": "string",
  "definition": "string",
  "properties": [
    "string",
    "string",
    "string"
  ],
  "formula": "string"
}
```

*   `title`: The main title of the video. This will be displayed in the first scene.
*   `definition`: A concise definition of the topic. This will be displayed in the second scene.
*   `properties`: A list of key properties, facts, or features of the topic. Each string in the array will be displayed as a separate bullet point. It is recommended to have at least 3 properties.
*   `formula`: A mathematical formula related to the topic. This should be written in LaTeX format. The formula will be rendered in the video using KaTeX.

## AI Prompt for Generating `content.json`

You can use the following prompt to ask an AI assistant to generate the content for you. Just replace `[Your Topic]` with the subject you want to create a video about.

### The Prompt

> You are an expert in creating educational content. Your task is to generate a JSON object for a short educational video about `[Your Topic]`. The JSON object must conform to the following schema:
>
> ```json
> {
>   "title": "string",
>   "definition": "string",
>   "properties": [
>     "string",
>     "string",
>     "string"
>   ],
>   "formula": "string"
> }
> ```
>
> -   The `title` should be a short, engaging question about the topic.
> -   The `definition` should be a clear and concise explanation of the topic.
> -   The `properties` should be a list of at least three important facts or characteristics.
> -   The `formula` should be a key formula related to the topic, written in LaTeX format.
>
> Please provide only the JSON object as the response.
>
> **Example for the topic "Photosynthesis":**
> ```json
> {
>  "title": "What is Photosynthesis?",
>  "definition": "Photosynthesis is the process used by plants, algae, and certain bacteria to harness energy from sunlight and turn it into chemical energy.",
>  "properties": [
>    "It occurs in the chloroplasts of plant cells.",
>    "The primary inputs are sunlight, water, and carbon dioxide.",
>    "The main outputs are glucose (for energy) and oxygen."
>  ],
>  "formula": "6CO_2 + 6H_2O \\rightarrow C_6H_{12}O_6 + 6O_2"
> }
> ```

## How to Use the Generated Content

1.  Copy the JSON object generated by the AI.
2.  Open the `public/content.json` file in this project.
3.  Paste the new JSON content into the file, replacing the existing content.
4.  Save the file.
5.  Run `npm run dev` to start Remotion Studio and see your new video!
